# Лабораторная работа 7

## Задание
Необходимо реализовать программу, которая позволит как шифровать,
так и расшифровывать любые файлы (с любым расширением) при помощи шифра Вернама.
Предусмотреть возможность генерации ключа `K` с использованием метода Диффи-Хеллмана.

## Шаги выполнения
- [ ] создай утилитный класс `Vernam` с логикой задания в пакете `io.allitov`.
- [ ] реализуй задание. Можно использовать методы, расположенные в классе `CryptoUtils`.
- [ ] пример чтения и вывода данных можно посмотреть в файле `Shamir` и `Main`.
